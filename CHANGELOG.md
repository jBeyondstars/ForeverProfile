# Forever Profiles v0.3.0

## Added

- **FPS automation.** Apply a performance profile after FPS stays below a configured threshold. Set a separate recovery threshold, duration, and target to return to higher graphics settings while the performance profile is active.
- **Saved settings.** Inspect every stored graphics variable and its exact value, with sections for general, raid, and shared settings.
- **Profile sharing.** Export a profile as an FP1 string and import it to create a new profile.
- **More graphics settings.** Profiles now capture ground clutter fade for general and raid settings where available, always-on sharpening, and the high-resolution texture preference.

## Interface

- Profile cards now show quality and active state and offer a one-click **Apply** button.
- Slider handles stay visible above the track in the Favorite bar and Automation panels.

Use **Update** to capture newly supported graphics settings in an existing profile. For example, configure **FPS drop** to apply Medium after 5 seconds below 80 FPS and **FPS recovery** to apply High after 15 seconds above 100 FPS.

**Game version** — World of Warcraft: Forever 1.60.1 (Interface 16001).
